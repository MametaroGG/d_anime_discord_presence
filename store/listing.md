# ストア掲載文案

## 短い説明（132文字以内）

dアニメストアで視聴中の作品名・話数・サブタイトルを Discord のステータスに表示します。ネイティブアプリのインストールが別途必要です。

## 詳細説明

【できること】
- dアニメストア再生中の作品名を Discord Presence に表示
- 話数・サブタイトル・再生進捗の表示
- （任意）作品サムネイルの表示

【必要なもの】
1. この Chrome 拡張
2. 同梱手順で入れるネイティブホスト（Windows）
3. Discord デスクトップアプリ
4. 自分で作成した Discord Application ID（インストーラで設定）

※ 拡張だけでは動作しません。インストール手順はサポート／リポジトリの RELEASE.md を参照してください。

【使い方】
1. ネイティブホストをインストール
2. この拡張を有効化
3. Discord を起動した状態で dアニメストアを再生
4. プレイヤーの時間表示を「現在 / 総時間」形式にする

【プライバシー / 利用規約】
視聴情報はローカルの Discord にのみ渡し、開発者サーバーへ送信しません。
詳細はプライバシーポリシーおよび利用規約を参照してください。
