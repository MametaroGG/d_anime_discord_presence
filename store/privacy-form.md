# Chrome Web Store 審査フォーム記入例

ダッシュボードの「プライバシー」関連項目用です。必要に応じて文言を調整してください。

---

## 単一用途の説明

dアニメストアの再生ページから視聴中の作品名・話数・サブタイトル・再生時間を取得し、ローカルのネイティブホスト経由で Discord の Rich Presence（視聴ステータス）に表示することだけを目的としています。広告表示、トラッキング、他サイトへのアクセスは行いません。

---

## nativeMessaging が必要な理由

Chrome 拡張単体では Discord デスクトップアプリへ Rich Presence を送信できないため、ローカル PC 上のネイティブホストアプリケーションと通信するために nativeMessaging を使用します。送信内容は視聴中の作品情報（タイトル、話数、サブタイトル、再生時間、任意でサムネイル URL）のみです。

---

## storage が必要な理由

拡張の設定画面で選択した「サムネイル表示のオン/オフ」を保存・読み込むために chrome.storage を使用します。視聴履歴や個人情報の保存には使用しません。

---

## ホスト権限が必要な理由

dアニメストアの再生ページ（https://animestore.docomo.ne.jp/animestore/sc_d_pc*）上に表示されている作品名・話数・サブタイトル・再生時間を読み取り、Discord Presence へ反映するために必要です。対象は当該再生ページのみです。

---

## リモートコードを使用していますか？

**いいえ、リモートコードを使用していません** を選択してください。

（いま「はい」になっている場合は切り替えてください）

理由:
本拡張の JavaScript はすべて拡張パッケージ内に含まれています。外部の JS / Wasm を読み込んだり、eval で外部コードを実行したりしません。サムネイル表示時に画像 URL（CDN / 画像プロキシ）を Discord へ渡すことがありますが、これは画像アセットでありリモートコードではありません。

---

## データ使用（収集するユーザーデータ）

次をチェック:

- [x] **ウェブサイトのコンテンツ**  
  （再生ページ上の作品名・話数・サブタイトル・再生時間、任意でサムネイル画像 URL）

次は原則チェックしない（該当しない）:

- 個人を特定できる情報
- 健康に関する情報
- 財務状況や支払いに関する情報
- 認証に関する情報
- 個人的コミュニケーション
- 位置情報
- ウェブ履歴（閲覧履歴一覧の収集はしない）
- ユーザーのアクティビティ（クリック追跡等はしない）

補足（審査向けの認識）:
ページ内容を読むのは Discord Presence 表示のためだけです。開発者サーバーへ送信・保存しません。Discord デスクトップアプリへはローカル通信で渡します。

---

## 開示内容が正しいことの宣言

次の 3 つすべてにチェック:

- [x] 承認された用途以外の目的で、ユーザーデータを第三者に販売または転送しない
- [x] アイテムの単一の目的と関係のない目的で、ユーザーデータを使用または転送しない
- [x] 与信判断や貸付を目的として、ユーザーデータを使用または転送しない
